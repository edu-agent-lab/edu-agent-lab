# edu-agent-lab

교사의 수업 준비를 돕는 AI 에이전트 서비스를 만들어가는 과정을 담은 저장소입니다. MCP로 외부 서비스를 다루는 법부터 시작해, 이를 하나의 에이전트로 통합하는 것까지 단계적으로 진행합니다.

## 프로젝트 구성

| 단계 | 프로젝트 | 내용 |
|---|---|---|
| 1 | [Notion 페이지 검색 및 요약](apps/notion-search) | MCP 클라이언트를 직접 구현해 Notion 팀스페이스에서 자연어 질의로 페이지를 검색·요약 |
| 2 | [AI 챗봇 기반 수업계획안 생성] | 챗봇을 통해 수업계획안을 생성하고 외부 서비스와 연동 |
| 종합 | [AI 기반 수업 활동 에이전트 서비스] | 여러 외부 서비스를 엮어 다양한 수업자료를 생성하는 에이전트로 통합 |

프로젝트 1, 2에서 만든 MCP 클라이언트와 챗봇 로직은 `packages/`에 공통 모듈로 두고, 종합 프로젝트에서 가져다 확장합니다.

## 저장소 구조 (초안)

```
edu-agent-lab/
├── packages/       # 프로젝트 간 공유되는 핵심 로직 (MCP 클라이언트, 요약, 챗봇 코어)
├── apps/           # 프로젝트별 실행 가능한 서비스
├── docs/           # 프로젝트별 설계 문서, 와이어프레임
└── tests/
```

각 프로젝트의 상세한 구현 방식과 MCP 연동 방식은 `apps/` 하위 각 프로젝트 폴더의 README를 참고해 주세요.
