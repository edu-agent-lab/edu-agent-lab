# "좋은 검색"과 "좋은 요약"의 평가 기준 (Day2 Step 4)

> 상태: **초안 — 팀 확정 필요**. 가이드 예시를 그대로 옮겨왔고, 아직 팀 논의로 확정한 값(N 등)은 아님.

## 좋은 검색의 기준

- **정확도**: 골든셋 기대 결과 중 상위 N개 안에 정답 페이지가 포함되는 비율
  - N 값 미정 — 골든셋 항목별 기대 결과 건수가 1~7건으로 편차가 커서, 고정 N보다는
    "기대 결과 건수만큼"을 기준으로 할지 논의 필요
- **재현율**: 관련 있는 페이지를 놓치지 않고 찾아내는 비율
- **노이즈**: 전혀 관련 없는 페이지가 결과에 섞이지 않는지

## 좋은 요약의 기준

- **핵심 정보 누락 없음**: 제목만 봐선 알 수 없는 실질적 내용 포함
- **길이 기준**: 2~3문장 또는 불릿 3개 이내 (`prompt.py`의 `SUMMARIZE_PAGE_PROMPT`가 이미 "3~4문장"으로 지정 —
  이 문서 확정 시 프롬프트도 같이 맞출지 확인 필요)
- **원문 왜곡 없음**: 요약이 원문과 다른 내용을 말하지 않는지

## 확정 시 반영할 곳

- N 값, 요약 길이 등이 정해지면 `prompt.py`의 `SUMMARIZE_PAGE_PROMPT`와 이 문서를 함께 갱신
- 실제 정확도/재현율/노이즈 측정은 `docs/notion-search/golden-set.md`의 기대 결과와 비교해서 수행
