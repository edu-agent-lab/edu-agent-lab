# NCIC 검색 평가 — Vector vs Hybrid 비교 결과

> 골든셋 22건(`golden-set.jsonl`), 데이터 9,784건, 임베딩 `dragonkue/BGE-m3-ko`, variant=v2.
> 재현: `cd apps/ncic-rag && python eval_ncic.py --compare`

## 결론 — Hybrid 채택

| mode | Top-1 | R@3 | R@10 | 노이즈 | 통과 |
|---|---|---|---|---|---|
| bm25 | 7/13 | 0.58 | 0.79 | 3 | 10/22 |
| dense | 10/13 | 0.71 | **0.86** | 4 | 12/22 |
| **hybrid** | **11/13** | **0.72** | 0.85 | **2** | **14/22** |

R@10은 dense가 0.01 높지만, 순위(Top-1)와 노이즈에서 hybrid가 낫다. LLM에 넘길
상위 5건의 품질이 중요하므로 hybrid를 쓴다.

**둘이 서로를 메우는 지점이 실제로 확인됐다.**

| 케이스 | bm25 | dense | 왜 |
|---|---|---|---|
| `topic-01` 개발과 환경 보전 토론 | 0.50 | 1.00 | 어휘가 "환경 보전" vs 원문 "환경 보존"으로 어긋난다 |
| `doctype-03` 인공지능 기초 과목의 성격 | 0.00 | 1.00 | 질의가 서술형이라 겹치는 낱말이 거의 없다 |
| `lexical-03` 저작권 | 0.50 | 0.33 | 정확 어휘는 BM25가 낫다 |
| `semantic-01` 태양광·풍력 | 0.33 | 0.67 | "재생에너지"를 질의에 쓰지 않았다 |

## 튜닝 과정 — 무엇을 왜 바꿨나

### ① BM25 토크나이저: 어절 → 어절 + 문자 2-gram (가장 큰 개선)

`lexical-03`("저작권")이 6건 중 **0건**이었다. 원문이 "저작권을", "저작권법을"이라
어절 분리로는 "저작권"과 다른 토큰이 되기 때문이다.

문자 2-gram을 더하면 `저작권을 → 저작,작권,권을` / `저작권 → 저작,작권`으로 겹친다.

| | R@10 (bm25) | R@10 (hybrid) | 통과 (hybrid) |
|---|---|---|---|
| 어절만 | 0.53 | 0.78 | 9/22 |
| 어절 + 2-gram | **0.79** | **0.85** | **12/22** |

형태소 분석기(`kiwipiepy`) 없이 이만큼 올랐다. 의존성을 하나 안 늘렸고, 이 방식으로
부족한 게 나올 때 붙이면 된다.

### ② doc_type 가중치: 비성취기준 0.9

"체육 안전 지도"에 교수·학습 지침이 성취기준보다 위로 오는 경우가 3건 있었다.
점수 차가 0.008~0.026으로 작아 10%만 깎아도 뒤집힌다.

| 비성취기준 가중치 | Top-1 (dense) |
|---|---|
| 1.0 | 7/13 |
| 0.95 | 9/13 |
| **0.9** | **10/13** |
| 0.8 | 10/13 (노이즈 증가) |

### ③ BM25 비중: 0.4 → 0.15

| BM25_WEIGHT | Top-1 | 통과 |
|---|---|---|
| 0.7 | 8/13 | 12/22 |
| 0.4 | 9/13 | 12/22 |
| **0.15** | **11/13** | **14/22** |

BM25는 순위를 정하는 주력이 아니라 dense가 놓친 정확 어휘를 끌어올리는 **보조**다.
비중이 낮을 때 가장 좋다. 0.10~0.20 구간이 평평해 중간값을 골랐다.

### ④ `course` 필터 추가

골든셋이 `course`로 좁히는 케이스(`special-03` 특수교육 진로와 직업)를 쓰는데
`retrieve.py`에 그 필터가 없어 시각장애인 자립 생활 과목이 결과를 채웠다.
메타 적합성 0.95 → 1.00.

## 남은 실패 8건 — 원인과 대응

| 케이스 | 증상 | 원인 | 대응 |
|---|---|---|---|
| `empty-01`, `empty-02` | 0건이 정답인데 결과가 나옴 | **점수 임계값으로는 못 막는다** (아래 참고) | LLM이 관련성을 판단하게 하거나 reranker |
| `doctype-03` | 다른 과목의 "성격"이 1위 | 정보과 4개 과목의 성격 문서가 거의 동일 | 질의에서 `course`를 추출해 필터 (프로젝트 1 `classify_query` 역할) |
| `doctype-01` | "평가의 방향"이 "평가 방법"보다 위 | 둘 다 같은 페이지의 평가 절 | 실사용상 문제 없음. 정답을 둘 다 인정하도록 골든셋을 완화할 수도 있다 |
| `lexical-03` | 저작권 6건 중 2건만 | 6개 과목에 흩어져 있어 Top-10으로 다 못 담음 | 질의 자체가 비현실적일 수 있음(교사가 전 과목 저작권을 한 번에 찾지 않는다) |
| `semantic-01` | 재생에너지 3건 중 1건 | 가장 어려운 의미 검색 | 남겨둠. reranker를 시험할 때 첫 후보 |
| `topic-03`, `filter-02` | 인접 성취기준이 4~5위에 | 같은 영역(인공지능 개념, 분수 나눗셈)이라 의미가 실제로 가깝다 | Top-5를 LLM에 넘기면 LLM이 걸러낸다 |

### 점수 임계값이 안 되는 이유 (실측)

0건이어야 하는 질의의 1위 점수가 정상 질의보다 높다.

| 질의 | 1위 코사인 |
|---|---|
| `empty-02` 중학교 국어 판소리 창법 (**정답 0건**) | 0.569 |
| `topic-01` 개발과 환경 보전 토론 (정답 있음) | 0.526 |
| `lexical-01` 인수분해 (정답 있음) | 0.497 |

코사인 유사도는 "관련 있음"의 절대 기준이 못 된다. 전역 임계값을 두면 정상 질의가
먼저 죽는다. RAG에서 통상적인 처리대로 **검색은 후보를 주고, 관련 없으면 LLM이
"적절한 성취기준이 없습니다"라고 답하게** 하는 쪽이 맞다.
